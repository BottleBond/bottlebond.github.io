This is to define the workflow for editing episodes within the Bottle Bond network. 

## Edit

Editing is done by exporting projects to storage within Google Drive. from there we import into Resolve and then relink the media. [Instructional](https://www.youtube.com/watch?v=_zrCKccQZoU)

- All Davinci Projects should be stored in the Top Level folder for the episode  ( The Date folder inside footage)
- Follow the naming convention - 1.0_XXEpisodeNameXX
- Version Glossary
    - 1.X - Rough Cut - Extraneous Content Cut, Rough focus.
        - 1.5 - fine cut - During this we are fine tuning the cuts to be exact.
    - 2.X - Picture Lock - Working Audio
    - 3.X - Audio Complete - Podcast Episode exported - Working Color
    - 3.X - Color complete - Final reviews
    - final - No further alterations.
